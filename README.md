# Computer Graphics – Portfolio

Welcome! This repository serves as a **central portfolio** for all my assignments from the:

**Computer Graphics course**

It collects and organizes the work developed throughout the course, covering fundamental concepts of 3D computer graphics such as transformations, projection, rasterization, and lighting.

Each assignment focuses on a different stage of the graphics pipeline, gradually building a complete rendering system from scratch in Python.

---

## Assignments

### 1. [Assignment 1 – Triangle Rasterization & Shading](https://github.com/thodorisvlachakis/triangle-rasterization-and-shading)
**Topics:**
- Triangle rasterization (scanline algorithm)
- Barycentric / linear interpolation
- Basic Gouraud shading
- Image generation from 2D primitives

---

### 2. [Assignment 2 – Transformations & Perspective Projection](https://github.com/thodorisvlachakis/transformations-and-perspective-projection)
**Topics:**
- Affine transformations (rotation, translation, scaling)
- Camera modeling (view transformation)
- Perspective projection
- 3D to 2D rendering pipeline
- Reuse of rasterization utilities from Assignment 1

---

### 3. [Assignment 3 – 3D Rendering: Lighting, Shading & Viewing Pipeline](https://github.com/thodorisvlachakis/3d-rendering-pipeline-lighting-shading)
**Topics:**
- 3D rendering pipeline implementation
- Phong illumination model
- Gouraud and Phong shading techniques
- Surface normals computation
- Multiple light sources
- Integration of full graphics pipeline (camera → projection → rasterization → shading)
